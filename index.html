Comment ça marche

Tout est stocké dans pro.md et perso.md, dans ton dépôt GitHub privé cap-data.

Ajouter une tâche depuis l'iPhone

Ouvre pro.md dans GitHub (ou l'app depuis l'iPhone), puis ajoute une ligne en bas :

- Relancer @David #PNowtâche pour aujourd'hui
- ! Préparer revue 📅2026-06-20haute priorité, datée

La syntaxe complète

#motcatégorie
@nompersonne concernée
! / __priorité haute / basse (seule = normale). ↓ reste accepté.
📅2026-06-20 ou demain, lundi, le 15…date d'échéance
r:semaine ou 🔁semainerécurrence (voir ci-dessous)
ligne indentée dessousnote libre de la tâche

Les parents (tâches qui en regroupent d'autres)

Un parent est un dossier à suivre dans le temps. Il a un début et une fin. Une tâche peut lui être rattachée : elle devient une sous-tâche.

= Mon parentle = en tête crée un parent
📅2026-06-15date de début du parent
🏁2026-07-30date de fin du parent
^pnow-v2l'étiquette du parent (son identifiant)
^pnow-v2 sur une tâchela rattache à ce parent

Dans l'app, tout se fait sans taper : choisis « Parent » dans le panneau, ou « Rattacher à un parent » sur une tâche. L'onglet « Parents » montre la frise.

Les récurrences

r:jour / r:3jtous les jours / tous les 3 jours
r:semaine / r:2schaque semaine / toutes les 2 semaines
r:lundichaque lundi
r:2s-lundiun lundi sur deux
r:mois / r:3mchaque mois / tous les 3 mois
r:le-15le 15 de chaque mois
r:1er-mardile 1er mardi du mois (2e, 3e, 4e, dernier)
r:dernier-jourdernier jour du mois
r:anchaque année

Quand tu coches une récurrence, la prochaine occurrence se cale sur le calendrier prévu. Pas d'empilement après une absence : une seule occurrence à la fois.

Archivage

Les tâches terminées restent visibles 30 jours. Ensuite elles partent automatiquement dans archive.md, dans le même dossier.
