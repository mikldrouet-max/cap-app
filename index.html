Comment ça marche

Tout est stocké dans pro.md et perso.md, dans ton dépôt GitHub privé cap-data. Les fichiers sont chiffrés AES-256-GCM — seule ta phrase secrète les déchiffre.

Ajouter une tâche depuis l'iPhone

Bouton + en bas à droite, ou directement dans pro.md sur GitHub :

- Relancer @David #PNowtâche pour aujourd'hui
- ! Préparer revue 📅2026-06-20haute priorité, datée

Capture vocale (raccourci Apple). Un raccourci dicte une note et dépose un fichier dans le dossier inbox/ du dépôt. À la prochaine ouverture de Cap. (ou en tirant pour rafraîchir), la note devient une tâche et le fichier est supprimé. La même syntaxe fonctionne à l'oral : « point urgent relancer David lundi » → ! … 📅lundi.

Tirer pour rafraîchir. Tout en haut de la liste, tire vers le bas et relâche : Cap. recharge depuis GitHub et importe les notes vocales en attente.

Pastille sur l'icône (iPhone). iOS exige la permission Notifications pour afficher la pastille d'une app installée. À la première ouverture, Cap. propose de l'activer. Refusée par erreur ? Réglages › Notifications › Cap. › autoriser, avec « Pastilles » activé.

Les statuts

- [ ]Ouvert — apparaît dans le bloc de sa date
- [/]En cours — point orange, reste dans le bloc date
- [x]Clos — rayé, déplacé dans "Terminées"
- [~]En attente — bloc dédié, non compté dans retards ni badge

Le statut se change depuis le menu rapide (clic droit / appui long) ou le panneau d'édition.

Les parents (tâches qui en regroupent d'autres)

Un parent est un dossier à suivre dans le temps. Il a un début et une fin. Une tâche peut lui être rattachée : elle devient une sous-tâche.

= Mon parentle = en tête crée un parent
📅2026-06-15date de début du parent
🏁2026-07-30date de fin du parent
^pnow-v2l'étiquette du parent (son identifiant)
^pnow-v2 sur une tâchela rattache à ce parent

Dans l'app, tout se fait sans taper : choisis « Parent » dans le panneau, ou « Rattacher à un parent » sur une tâche. L'onglet « Parents » montre la frise Gantt.

Les récurrences

r:jour / r:3jtous les jours / tous les 3 jours
r:semaine / r:2schaque semaine / toutes les 2 semaines
r:lundichaque lundi
r:2s-lundiun lundi sur deux
r:mois / r:3mchaque mois / tous les 3 mois
r:le-15le 15 de chaque mois
r:1er-mardile 1er mardi du mois (2e, 3e, 4e, dernier)
r:dernier-jourdernier jour du mois
r:anchaque année

Quand tu coches une récurrence, la prochaine occurrence se cale sur le calendrier prévu. Pas d'empilement après une absence : une seule occurrence à la fois.
